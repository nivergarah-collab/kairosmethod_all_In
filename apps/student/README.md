# Estudiante

Aplicación del estudiante: **un solo proyecto React responsive** (PC y celular), sin subcarpetas `web/` ni `mobile/`.

- La web se adapta al tamaño de pantalla con diseño responsive.
- El apk de Android podría salir del mismo proyecto con Capacitor cuando se implemente esa fase; hoy no hay configuración `android/` ni workflow de build.
- Sin persistencia por ahora.

Ver [docs/mobile.md](../../docs/mobile.md). Estado: pendiente.
