# Portal

Página principal del despliegue.

- **Hoy:** índice simple que enlaza a los prototipos aislados.
- **Mañana:** se reutiliza para construir el dashboard real (gestor de espacios de trabajo).

Se publicará en la raíz de GitHub Pages después de crear/enlazar el repo y de implementar los prototipos base. Cada prototipo elegido cuelga de `<base-del-repo>/prototypes/<nombre>/`; el build exige que la lista elegida esté configurada y que cada enlace conserve esa base.
